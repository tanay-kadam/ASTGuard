# External evaluation cohort: rules frozen before scoring

Companion to SEVEN_DAY_STRENGTHENING_PROTOCOL_20261012.md. No model scores may be inspected to choose this cohort. DiverseVul is a candidate external source, not presumed independent of PrimeVul. The official PrimeVul test remains locked and is used here only as an exclusion reference; no model predictions are computed on it.

Use all 235,768 normalized PrimeVul rows as conservative exposure/exclusion references, including every official source role. Use all 330,492 normalized DiverseVul rows as candidate external records. Construct global transitive components across both sources from raw SHA256, whitespace-normalized SHA256, newly computed lexical fingerprints, normalized repository/project plus commit, CVE and pair identifiers where available, and exact verified near clones. Missing metadata is disclosed rather than interpreted as independence.

The lexical audit ignores whitespace/comments and retains token kinds and literal text, without identifier renaming. For source rejected by the existing lexer, a separate audit-only fallback retains each otherwise unsupported character as a literal unknown token. This avoids empty fingerprint collapse and does not alter model preprocessing. Record the fallback count. Near clones require five-token shingle-set Jaccard >=0.90 and token-count ratio >=0.80, with at least five tokens. A global frequency-ordered prefix join generates candidates; exact Jaccard verification follows. Verify candidate completeness against brute force on small fixtures. This certifies the specified rules only, not semantic independence, unseen projects, absence of pretraining exposure, or all possible clone definitions.

Exclude every DiverseVul row whose global component touches any PrimeVul row. Within the remainder, retain all labels and natural prevalence; do not balance or sample according to results. Preprocess with the frozen CodeBERT/GraphCodeBERT recipes, retaining the existing extraction-failure behavior. Exclude model-sequence collisions against tokenized inputs from all PrimeVul rows, for either model representation; purge their complete candidate components. Keep one common retained population for all architectures. Save membership, labels, component IDs, exclusion reasons, raw input hashes and preprocessing hashes before inference.

Feasibility gate: at least 1,000 functions, 100 vulnerable functions, 100 benign functions and 20 dependence components after all exclusions. This is a pragmatic minimum, not a power guarantee. If the gate fails, report no adequate external cohort; do not quietly lower the cutoff or choose a different favorable subset. A separately audited fallback requires its own explicit exposure audit and frozen amendment before scores.

Only the original real TUNE selects checkpoints. Evaluate the frozen new cohort after its manifest is sealed. Primary AP contrasts are attention authentic-minus-shuffled, authentic-minus-sequence; centered-minus-sequence; ReGVD native-minus-permuted and native-minus-self. Report all five contrasts with per-seed results and 95% paired seed t intervals, and paired component bootstrap intervals (10,000 resamples, analysis seed 20261012). Treat inference as exploratory follow-up, without equivalence or causal vulnerability-semantic claims. All interventions use consistent FP32 logits. Do not use the cohort to tune thresholds, budgets, model selection, or reporting choices.
