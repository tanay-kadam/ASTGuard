FORMAL EQUATIONS — IMPLEMENT EXACTLY
==========================================================

The implementation and paper must use the same mathematical definition.

1. SEQUENCE-ONLY BASELINE

For layer l, head h, query token i, and key token j:

S_seq,ij^(l,h) =
    Q_i^(l,h) (K_j^(l,h))^T / sqrt(d_h)

A_ij^(l,h) =
    softmax_j(S_ij^(l,h))

O_i^(l,h) =
    sum_j A_ij^(l,h) V_j^(l,h)

2. STRUCTURAL RELATION MATRICES

For relation r in {AST, DFG}:

M_ij^r = 1
    if tokens i and j are connected by structural relation r

M_ij^r = 0
    otherwise

Special tokens and padding must not receive structural edges.
The matrices must follow the exact tokenizer truncation/alignment.

3. FIXED-STRUCTURE BASELINE

S_fixed,ij^(l,h) =
    Q_i K_j^T / sqrt(d_h)
    + sum_{r in {AST,DFG}}
        beta_r^(l,h) M_ij^r

AST-fixed:
    enable AST only.

DFG-fixed:
    enable DFG only.

AST+DFG-fixed:
    enable both relations.

There is NO contextual gate in these fixed baselines.

4. ASTGUARD ADAPTIVE GATE

g_i,r^(l,h) =
    sigmoid(
        W_r^(l,h) h_i^(l-1)
        + b_r^(l,h)
    )

Therefore:

0 <= g_i,r^(l,h) <= 1

5. ASTGUARD ATTENTION SCORE

S_ASTGuard,ij^(l,h) =
    Q_i K_j^T / sqrt(d_h)
    + sum_{r in {AST,DFG}}
        g_i,r^(l,h)
        beta_r^(l,h)
        M_ij^r

Then use the normal transformer equations:

A_ij^(l,h) =
    softmax_j(S_ASTGuard,ij^(l,h))

O_i^(l,h) =
    sum_j A_ij^(l,h) V_j^(l,h)

CRITICAL:
The AST/DFG term is a SOFT ADDITIVE BIAS.
It must never become a hard attention mask.
Normal semantic attention remains unrestricted.

6. TRAINING OBJECTIVE

Use weighted binary cross-entropy by default:

L_BCE =
    -(1/N) sum_n [
        w_1 y_n log(p_n)
        + w_0 (1-y_n) log(1-p_n)
    ]

Estimate w_0 and w_1 from TRAINING DATA ONLY.
Do not use validation or test labels to estimate class weights.

All controlled variants must start from the same
microsoft/codebert-base checkpoint:

ROLE
----
You are the lead ML research engineer and reproducibility owner for a research project intended to produce a defensible academic paper, not a demo repository.

Your job is to implement, test, run, and audit the project end-to-end. You must not stop after scaffolding files. PROJECT
-------
ASTGuard: Adaptive Relation-Gated Structural Attention for C/C++ Vulnerability Detection

CORE RESEARCH QUESTION
----------------------
Can a pretrained code transformer improve realistic C/C++ vulnerability detection by learning WHEN and WHERE AST and data-flow relations should influence self-attention, instead of applying a fixed structural mask or a single global structural weight?

The novelty to test is NOT "using AST + DFG." Existing work already uses code structure and data flow.

The specific proposed contribution is:

1. Preserve ordinary pretrained transformer token-to-token attention.
2. Inject AST and DFG relations as SOFT ADDITIVE attention biases, not hard masks.
3. Learn relation-specific structural magnitudes.
4. Learn contextual gates that vary by token, attention head, and transformer layer.
5. Compare this adaptive mechanism against the identical sequence-only backbone and fixed-structure variants.
6. Analyze learned gates to determine when syntax vs. data flow is actually used.

Do not write first-of-kind claims in documentation unless a literature review verifies them.

==========================================================
A. MATHEMATICAL SPECIFICATION
==========================================================

For transformer layer l, attention head h, query token i, key token j:

score_ij^(l,h) =
    Q_i K_j^T / sqrt(d_h)
    + sum_r [
        g_i,r^(l,h)
        * beta_r^(l,h)
        * M_ij^r
      ]

where initially:

r in {AST, DFG}

M_AST:
    token-token structural relation matrix derived from AST relationships.

M_DFG:
    token-token relation matrix derived from data-flow relationships.

beta_r^(l,h):
    learned structural bias magnitude for relation r, layer l, and head h.

g_i,r^(l,h):
    token-conditioned adaptive structural gate:

    g_i,r^(l,h) = sigmoid(
        W_r^(l,h) h_i^(l-1) + b_r^(l,h)
    )

Therefore:

0 <= g_i,r^(l,h) <= 1

CRITICAL INVARIANT:
Normal semantic self-attention MUST remain unrestricted.

AST and DFG provide additive priors. They do NOT become a hard mask that prevents ordinary token interactions.

CRITICAL EQUIVALENCE TEST:
If every structural contribution is explicitly zeroed, the model must numerically match the sequence-only CodeBERT model initialized from the same weights, within normal floating-point tolerance.

If this test fails, the controlled comparison is invalid and must be fixed before experiments continue.
